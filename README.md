# SmartStore POS

A responsive General Store POS/billing website made with HTML, CSS and vanilla JavaScript.

## Features
- Product & inventory management
- Billing/cart with discount and GST
- Cash, UPI, Card and Udhaar payment modes
- Bill-specific UPI QR
- Printable 80mm-style receipt
- WhatsApp bill sharing
- Customers
- Udhaar ledger
- Sales history
- Daily/date-range reports
- Low-stock dashboard
- CSV export
- JSON backup/restore
- Dark mode
- LocalStorage persistence
- GitHub Pages compatible

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload the whole project while keeping:
`index.html`
`assets/style.css`
`assets/app.js`

Then enable GitHub Pages from Settings -> Pages -> Deploy from branch.
